## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/sumaiya-mugdha/AI_ML_Learning.git
   cd AI_ML_Learning
   ```

2. Install required dependencies:
   ```bash
   pip install numpy pandas jupyter matplotlib scikit-learn
   ```

3. Launch Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
